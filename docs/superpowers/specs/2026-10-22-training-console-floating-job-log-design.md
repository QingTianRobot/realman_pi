# 训练控制台：浮动任务日志小窗

日期：2026-10-22 · 适用：server5090 :8780 训练控制台（`src/training/realman_training/web`）

## 问题

任务日志是贴底的全宽抽屉（`min(60vh, 520px)` 高），打开时挡住页面下半部，页面还要为它留出同样高的底部留白。

## 目标

把任务日志改成一个浮动小窗：可在网页内自由拖动，可切换大小，不用时隐藏成右下角的悬浮按钮。

## 设计

在现有 `JobDrawer`（`drawer.ts`）上改外壳；任务列表、日志 WebSocket、取消任务、`job-ended` 事件的逻辑不变。

- **窗口**：`position: fixed` 的圆角卡片，层级在页面之上；`role="dialog"`、非模态、`aria-label="任务日志"`。去掉 `body.drawer-open` 的底部留白。
- **标题栏**：拖动它移动窗口（Pointer Events），位置限制在视口内；视口变化时自动拉回。标题栏有：标题“任务日志”、进行中任务数、取消任务（仅在选中任务进行中且非只读时显示）、尺寸切换（小/大）、隐藏。
- **两档尺寸**：
  - 小（默认约 360×260）：只有任务列表（状态 + 进度文字）。点某个任务会切到“大”并显示它的日志。
  - 大（默认约 760×460）：左边任务列表，右边日志，与现有抽屉布局相同。
- **拖角微调**：右下角拖动改尺寸，有最小值（小 280×180、大 480×300），最大不超过视口；拖完的尺寸记在当前这一档上。
- **隐藏**：窗口隐藏后右下角出现悬浮圆按钮，显示进行中任务数（> 0 时带一圈动效）；点它恢复，位置和尺寸不变。顶部“任务日志”按钮继续用来打开或隐藏窗口。Esc 隐藏窗口。`openDrawer(id)`（各页面的“查看日志”）会打开窗口、切到“大”并选中该任务。
- **轮询与连接**：只在窗口可见时轮询任务列表（5 s）并保持日志 WebSocket；隐藏时与现在的“关闭”一样停掉。悬浮按钮上的数字由 `main.ts` 现有的导航刷新提供，不新增轮询。
- **记忆**：`localStorage` 键 `training-console.job-log` 存 `{x, y, size, dims: {small, large}, hidden}`；读写都包在 try/catch 里，失败时使用默认值（右下角、隐藏）。刷新后恢复。
- **窄屏**（< 720px）：不能拖动、不能拖角，固定底部全宽、高约 55vh；小/大切换和隐藏保留。

## 测试

更新 `website/tests/training-console/console.spec.ts`（`npm run test:training`）（真实服务器 + 假步骤）：
- 打开后窗口是浮动的（不是全宽），页面没有底部留白；
- 拖动标题栏后位置改变；拖不出视口；
- 小/大切换改变尺寸和内容（小档没有日志区）；
- 隐藏后出现悬浮按钮并能恢复到原位置；
- 刷新后位置、档位、隐藏状态都恢复；
- “查看日志”打开大档并选中对应任务；Esc 隐藏。

另外在桌面宽度和手机宽度下各截一张图核对。

## 不做

- 不加拖拽或窗口库。
- 不支持多个日志窗口，也不支持吸附到边。
