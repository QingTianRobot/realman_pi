# Behavior Tree Monitor Theme, Startup, and Failure Details Design

## Goal

Make the read-only behavior-tree monitor visually consistent with
`golf-course-robot/gcr_behavior/web`, remove startup latency caused by coupling the
HTTP server to ROS Action readiness, and expose actionable failure reasons when a
node is selected.

## Decisions

- The reference implementation's actual palette is authoritative: dark charcoal
  top bar, light status strip/panels, compact bordered tree rows, and a right-hand
  inspector. The monitor keeps the existing Chinese labels and read-only boundary.
- `bt_server` starts before the Action readiness loop. A missing Action server may
  prevent the executor from starting, but must not prevent `/` and `/api/health`
  from becoming available.
- `/api/runtime` uses an executor-provided sequence as the cache validator. The
  server emits an `ETag` derived from the sequence and honors `If-None-Match` with
  `304 Not Modified`; the frontend polls once per second and treats 304 as a
  successful no-change response.
- Snapshot nodes may contain `failure_reason`; the snapshot root may also contain
  `failure_reason`. Reasons are generated by the executor/MoveJ node for validation
  errors, timeout, rejected goals, Action result messages, and exceptions.
- Selecting a failed node displays its reason in the inspector. Missing reasons
  render an explicit fallback message rather than an empty panel.

## Boundaries

The webpage remains read-only and never connects to ROS. The executor remains the
only tree ticker and Action client. No real-motion behavior changes are introduced.

## Verification

- Vitest verifies reference-style structure, dark/light palette tokens, 304 client
  handling, and failure detail rendering.
- C++/Python server tests verify ETag and conditional responses.
- Shell tests verify that server startup precedes Action readiness and that the
  executor still waits for the configured Action timeout.
- Production Docker build and a no-motion monitor smoke verify the packaged result.
